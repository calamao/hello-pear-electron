# Tic-Tac-Toe

I want an app that will allow playing tic-tac-toe games with friends.
The app should allow for listing my games and the different states:

- New created game
- Game where we have sent the invitation to another player
- Started game
  - My turn
  - Other player's turn
- Finished game
  It should allow for creating a new game, deleting previous games, invite a friend to a new game.

## Tasks

### Task 1

Create that basic UI.
The source of the data and the actions should be coming from a mock API that we will later wire up.
Make the UI as atractive and original as possible.
Change global styles so the whole app is consistent.

### Technical requirements

- Create a separate package for that UI in the UI packages folder
- Create the mock API package separately in the UI folder to wire up later. Use inMemory storage for the mock implementation.
